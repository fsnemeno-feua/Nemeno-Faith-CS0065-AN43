# Asynchronous Activity 1: Student Early Warning Tool using KNIME

This repository contains the required output for Asynchronous Activity 1. The project uses KNIME to predict the risk status from academic performance data.

## Files
- 'DemoEarlyWarningTool.knwf' - exported KNIME workflow
- 'student_performance_knime.csv' - dataset used by the workflow

## Algorithms
- Decision Tree
- Logistic Regression
- Random Forest

## How to Run
1. Import the '.knwf' file into the KNIME Analytics Platform.
2. Configure the CSV Reader and select Included dataset.
3. Execute all nodes.
4. Open the Scorer nodes to review the evaluation results.
